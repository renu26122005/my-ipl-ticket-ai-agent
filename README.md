# IPL Ticket Booking AI Agent

An AI-powered IPL ticket booking assistant built using Google's Agent Development Kit (ADK). The agent helps users search for IPL match tickets and book tickets through a conversational interface.

## Features

- Search for IPL matches and available tickets.
- Retrieve match details, including teams, venues, and ticket prices.
- Book tickets based on user requests.
- Conversational interaction using an AI agent.
- Tool integration for ticket searching and booking.

## Tech Stack

- **Python** – Backend development
- **Google ADK** – AI agent development
- **Gemini API** – Natural language understanding
- **JSON** – Mock ticket and match data

## How It Works

1. User interacts with the AI agent through a chat interface.
2. The agent understands the user's ticket booking request.
3. The `search_tickets` tool retrieves matching IPL ticket details.
4. The agent presents available matches, venues, and prices.
5. The `book_ticket` tool handles the booking request.
6. The agent provides a booking confirmation response.
